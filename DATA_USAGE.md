# Data usage and attribution

This repository distributes **author-generated numerical observations** and
computed evaluation tables, not source photographs, videos, source annotations,
image embeddings or third-party model checkpoints. Query and cluster identifiers
in the external CPU evidence are dataset-relative pseudonyms and carry no source
paths. Numerical files record measurements and correctness outcomes in the
specific evaluation protocol; they do not replace the benchmark providers'
underlying assets or official evaluation rules.

The included MIT LICENSE covers originally authored software. It does **not**
grant any license to redistribute or modify images, geographic metadata,
third-party annotations, trained weights, or upstream software. Dataset and
upstream code owners retain their own terms; consult the sources linked in
`docs/DATA_SOURCES.md` when independently obtaining original data or code.

The manuscript, accompanying numerical evidence, and research authors should
be cited when quoting experimental outcomes. Retain dataset citations as well.
